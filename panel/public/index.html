        Google Workspace Setup Instructions
        ▼
      

      

        
    
          
  1. Go to Google Cloud Console and create a project (or use existing)
    2. 
          
  2. Enable the following APIs under APIs & Services → Library: Gmail API, Google Calendar API, Google Drive API, Google Docs API, Google Sheets API, Google Slides API
    3. 
          
  3. Configure the OAuth consent screen (External is fine for personal use, add yourself as a test user)
    4. 
          
  4. Create an OAuth 2.0 Client ID (type: Desktop app)
    5. 
          
  5. Copy the Client ID and Client Secret into the form above
    6. 
          
  6. Click Add Account below and sign in with each Gmail account
    7.

        Slack Setup Instructions
        ▼
      

      

        
    
          
  1. Go to Slack API Apps and click Create New App → From scratch
    2. 
          
  2. Under OAuth & Permissions, add a Redirect URL: http://localhost:5000/slack/oauth/callback
    3. 
          
  3. Add Bot Token Scopes: channels:read, channels:history, chat:write, users:read, users:read.email, groups:read, groups:history, im:read, im:history, mpim:read, mpim:history, reactions:read, reactions:write, files:read
    4. 
          
  4. Add User Token Scopes: search:read
    5. 
          
  5. Go to Basic Information, copy the Client ID and Client Secret into the form above
    6. 
          
  6. Click Add Workspace below and authorize for each Slack workspace
    7.
