Setup Instructions ▼

  1. Go to Google Cloud Console and create a project (or use existing)
  2. Enable the Gmail API under APIs & Services → Library
  3. Configure the OAuth consent screen (External is fine for personal use, add yourself as a test user)
  4. Create an OAuth 2.0 Client ID (type: Desktop app)
  5. Copy the Client ID and Client Secret into the form above
  6. Click Add Account below and sign in with each Gmail account
